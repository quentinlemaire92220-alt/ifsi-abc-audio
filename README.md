# IFSI ABC — Ressources audio

Copies destinées au lecteur de l’application IFSI ABC Révisions. Les 178 fichiers conservent leur audio décodé ; les originaux Drive sont préservés. Les AAC bruts sont remuxés en M4A sans réencodage, les MP3 sont copiés à l’identique.

`manifest.json` associe chaque vocal historique à sa copie et à ses empreintes. Les reçus de téléchargement et les preuves privées ne sont pas publiés.

Cet hébergement est séparé de l’application pour respecter la taille maximale d’un site GitHub Pages. Les médias sont chargés à la demande et ne font pas partie du précache de l’application.
